# CivicBounce

> **Once you hit rock bottom, the only way is UP!**

CivicBounce is a civic resilience platform launching **Memorial Day 2026** — an emergency response network for builders, digital and IRL, bouncing out of the current political dumpster fire.

## What We Are Building

- Secure, decentralized forums for regional planning
- Zero-tracking Event Scheduler for IRL coordination
- HAM/CB Radio registry and regional frequency maps
- Offline-first resource catalogs and mutual aid guides

## Tech Stack

- **Blazor WASM** (.NET 10) + **Bootstrap 5**
- Hosted on **GitHub Pages** via GitHub Actions

## Local Development

```bash
cd src
dotnet restore
dotnet run
```

## Deploy

Push to `main` — GitHub Actions automatically builds and deploys to GitHub Pages.

## Philosophy

We take a **CB and HAM radio approach** — decentralized, redundant, operating adjacent to official emergency channels. No algorithms. No outrage farms. Just community infrastructure we control.
